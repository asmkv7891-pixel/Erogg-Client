## 项目简介

EROGG Client 是一个面向 Minecraft Fabric 1.21.11 的客户端模组。本客户端基于 [OpenHachimi](https://github.com/GzSakura1338/OpenHachimi) 1.21.1 源码，并完成了对 Minecraft 1.21.11 的适配与升级。
          
## 环境要求

- Minecraft Java Edition 1.21.11
- Fabric Loader（适用于 Minecraft 1.21.11）
- Fabric API（适用于 Minecraft 1.21.11）
- Java 21 或更高版本

建议使用与游戏版本匹配的 Fabric Loader 和 Fabric API，避免因版本不一致导致客户端无法启动。

## 安装

1. 安装 Minecraft Java Edition 1.21.11。
2. 为 Minecraft 1.21.11 安装 Fabric Loader。
3. 安装与 Minecraft 1.21.11 匹配的 Fabric API。
4. 将本项目发布的 `.jar` 文件放入 Minecraft 1.21.11 Fabric 实例的 `mods` 文件夹中。
5. 启动 Fabric 1.21.11 配置文件。

Windows 默认的游戏目录通常为 `%APPDATA%\\.minecraft\\mods`。如果使用启动器管理多个实例，请将文件放入对应实例的 `mods` 文件夹，而不是其他版本的目录。

## 使用

进入游戏后，按键盘上的 **右 Shift（Right Shift）** 键打开客户端界面。

如果快捷键与其他模组冲突，请在游戏设置或客户端按键设置中调整按键绑定（以实际构建版本提供的设置为准）。
